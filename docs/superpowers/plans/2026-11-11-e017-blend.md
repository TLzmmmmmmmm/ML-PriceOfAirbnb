# E017 E016-Text Blend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Determine whether a small fixed-weight blend of E016 and E012 improves validated RMSE, and generate a submission only if it meets the predefined gate.

**Architecture:** Reuse the existing tested `evaluate_blend` function and saved OOF arrays. Evaluate exactly four declared weights, select by mean fixed-fold RMSE, and if retained combine the validated E016 test predictions with predictions from the saved E012 full model.

**Tech Stack:** Python, pandas, NumPy, scikit-learn, joblib, pytest

**Spec:** User-approved E017 design in the 2026-11-11 conversation; project-wide rules are in `CHALLENGE_PLAN.md`.

## Global Constraints

- Test only E016/E012 weights `95/5`, `90/10`, `85/15`, and `80/20`.
- Use the fixed five-fold assignments and original-dollar RMSE.
- Retain only if mean RMSE improves by at least `0.3` and at least four folds improve.
- Do not retrain E012 or upload any generated CSV.
- Keep OOF arrays, model artifacts, and submission CSVs out of Git.

## Review Focus

- OOF arrays must align with the unchanged training-row order and fixed folds.
- Recorded hashes must match the OOF artifacts actually evaluated.
- Selection must use local OOF metrics, not the public leaderboard.
- Full-test predictions must use the same selected weights.
- A rejected experiment must not generate a submission.
